🔥 Connect Firebase
1Go to console.firebase.google.com → your project → Project Settings ⚙️ → scroll to Your apps → copy the config values below.
2Make sure Realtime Database and Email/Password Authentication are enabled in your Firebase project (same setup as the main MINES BD app).
3This admin panel reads all data using admin read access via the SDK. It never writes to Firebase Auth directly — password resets use Firebase Admin SDK via a Cloud Function, or you can manage auth from the Firebase console.
